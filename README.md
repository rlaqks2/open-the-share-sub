# 오픈더쉐어 · 나눔 DIY 학교 프로그램 홈페이지

선생님 대상 홈페이지입니다. 서버 없이 동작하는 정적 사이트(HTML/CSS/JS)라
무료 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 폴더째 올리면 됩니다.

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 본문 (프로그램 소개, 키트, 운영방식, 견적·구매, VOC, 후기, FAQ) |
| `css/style.css` | 디자인 |
| `admin.html` | **관리자 페이지** — 키트 단가 수정 |
| `js/prices.js` | 키트 기본 단가 (관리자 페이지에서 내보내 교체 가능) |
| `js/kits.js` | **키트 65종 데이터** — 나눔 대상 추천, 계절 태그 수정 |
| `js/config.js` | **사이트 설정** — 접수 주소(ENDPOINT), 연락처, 결제 방식 |
| `js/app.js` | 동작 (필터, 담기, 폼 전송, 후기 목록) |
| `assets/kits/` | DIY 키트북에서 잘라낸 키트 사진 (kNN = 키트북 페이지 번호) |
| `apps-script/Code.gs` | 접수 내용을 구글 시트에 쌓는 스크립트 |

## 1. 접수 내용을 구글 시트로 받기 (무료, 약 10분)
1. 구글 드라이브에서 새 **구글 시트**를 만듭니다. (예: "홈페이지 접수")
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여넣습니다.
   알림 메일을 받으려면 맨 위 `NOTIFY_EMAIL` 에 주소를 넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
5. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. `js/config.js` 의 `ENDPOINT: ""` 따옴표 안에 붙여넣고 저장합니다.

이제 제출할 때마다 시트에 `견적·구매신청`, `선생님의견(VOC)`, `수업후기` 탭이 자동으로 생기고 한 줄씩 쌓입니다.
- 견적 탭의 `status` 칸으로 진행 상황(신규 → 견적발송 → 결제완료 → 배송 → 기부완료)을 관리하세요.
- 후기 탭의 `approved` 칸에 **Y** 를 넣은 후기만 홈페이지에 공개됩니다. (학교명은 ○○초로 가려서 표시)

> ENDPOINT를 비워 두면 화면 왼쪽 아래 "미리보기 모드" 표시가 나오고, 제출 내용은 실제로 전송되지 않습니다.

## 2. 단가 관리 (관리자 페이지)
- 주소: `admin.html` (홈페이지 맨 아래 "관리자" 링크)
- 기본 단가는 `js/prices.js` 에 들어 있습니다. 지금은 15,000~35,000원 사이 **임시 단가**예요.
- 관리자 페이지에서 할 수 있는 일
  - 키트별 단가 직접 수정 (저장 전 변경분은 노란색으로 표시)
  - 검색·분류·난이도 필터, 열 제목 눌러 정렬
  - 현재 목록에 일괄 % 인상·인하, 금액 더하기·빼기, 한 금액으로 맞추기, 기본값 되돌리기
  - `prices.js` 내보내기 (기본 단가 파일 교체용), CSV 내보내기·가져오기 (엑셀 편집용)
- **저장하면 어디에 반영되나요?**
  - 구글 시트를 연결한 경우(ENDPOINT 설정): 시트의 `단가` 탭에 저장되고 **모든 방문자에게 바로 반영**됩니다. 시트에서 직접 고쳐도 반영돼요.
  - 연결 전(미리보기 모드): 비밀번호 없이 들어가지고, 저장값은 **그 브라우저에서만** 보입니다. 이때는 "prices.js 내보내기"로 받은 파일을 `js/prices.js` 와 바꿔 올리면 모두에게 반영됩니다.
- **관리자 비밀번호**: `apps-script/Code.gs` 맨 위 `ADMIN_KEY` 값을 바꾼 뒤 다시 배포하세요(배포 → 배포 관리 → 수정 → 새 버전). 비밀번호는 구글 서버에서만 확인하기 때문에 홈페이지 코드에 드러나지 않습니다. 기본값 그대로면 로그인이 되지 않아요.

## 3. 온라인 카드 결제를 붙이려면
현재는 학교 회계 절차에 맞춰 **견적 요청 → 견적서 → 학교장터/세금계산서/카드 결제** 흐름입니다.
홈페이지에서 바로 카드 결제를 받으려면 PG사(토스페이먼츠, 포트원 등) 가맹 계약과 사업자 정보가 필요하며,
결제 승인 처리를 위한 서버(또는 서버리스 함수)가 추가로 필요합니다.

## 4. 내 컴퓨터에서 미리 보기
`index.html` 을 더블클릭하면 브라우저에서 열립니다.

## 공개 전에 확인할 것
- 문구 중 **"1영업일 내 견적", "최소 10개", "100% 기부 연계", 프로그램별 학년·차시·인원** 등은 예시로 쓴 초안입니다. 실제 운영 기준에 맞게 고쳐 주세요.
- 키트별 **나눔 대상 추천**(`GIVE_BY_GROUP`, `GIVE_OVERRIDE`)도 실제 협력 기관에 맞게 수정하세요.
- 개인정보 수집 동의 문구와 개인정보처리방침 페이지를 준비하세요.
